## Verification Plan

### Automated Tests

No unit tests for Module 1 (foundation setup). Verification is via command execution.

### Manual Verification

All verification steps are designed to be run by a developer following the commands exactly.

---

#### Test 1: Backend Startup

**Prerequisites**: Python 3.12+ and uv installed

**Steps**:
1. Open terminal
2. Navigate to backend: `cd todo-web-app/backend`
3. Install dependencies: `uv sync`
4. Start server: `uv run uvicorn src.main:app --reload`
5. Wait for "Uvicorn running on http://127.0.0.1:8000" message
6. Open browser: Navigate to `http://localhost:8000/docs`
7. Verify Swagger UI loads with "Todo Web App API" title
8. Click on `/api/health` endpoint, click "Try it out", click "Execute"
9. Verify response contains `{"status": "healthy", "version": "0.1.0", ...}`

**Expected**: Server starts, Swagger docs load, health endpoint returns 200.

---

#### Test 2: Frontend Startup

**Prerequisites**: Node.js 20+ and pnpm installed

**Steps**:
1. Open terminal
2. Navigate to frontend: `cd todo-web-app/frontend`
3. Install dependencies: `pnpm install` (may already be done)
4. Start dev server: `pnpm dev`
5. Wait for "Ready" message in terminal
6. Open browser: Navigate to `http://localhost:3000`
7. Verify page loads without errors

**Expected**: Dev server starts on port 3000, page loads.

---

#### Test 3: Linter Verification

**Backend**:
```bash
cd todo-web-app/backend
uv run ruff check .
# Expected: No errors (or only warnings)
```

**Frontend**:
```bash
cd todo-web-app/frontend
pnpm lint
# Expected: No errors
```

---

#### Test 4: Docker Compose (Optional)

**Prerequisites**: Docker Desktop installed and running

**Steps**:
1. Open terminal
2. Navigate to: `cd todo-web-app`
3. Build and start: `docker-compose up --build`
4. Wait for both services to show "ready" messages
5. Open browser: `http://localhost:3000` (frontend)
6. Open browser: `http://localhost:8000/docs` (backend)

**Expected**: Both services accessible in containers.

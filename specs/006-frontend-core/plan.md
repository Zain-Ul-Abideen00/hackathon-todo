# Implementation Plan: Todo Web Frontend (Production Ready)

**Branch**: `006-frontend-core` | **Date**: 2026-01-11 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/006-frontend-core/spec.md`

## Summary

Build a production-ready frontend for the Todo web application with:
- **Landing page** with navbar, hero, features, and footer using Lightswind components
- **Theme system** with light/dark mode toggle (diag-down-right animation) and Chonkie.ai colors
- **Authentication pages** (login/signup) with form validation and password strength
- **Dashboard layouts** - sidebar on desktop (≥768px), bottom dock on mobile (<768px)
- **Task management UI** - CRUD operations with filtering, sorting, and pagination

**Technical Approach**: Next.js 16+ App Router with React 19, exclusive use of Lightswind UI components, TanStack Query for data fetching, Zustand for client state, Framer Motion for animations.

## Technical Context

**Language/Version**: TypeScript 5.x, Node.js 20+ LTS
**Primary Dependencies**: Next.js 16.1.1, React 19, Tailwind CSS v4, Framer Motion, TanStack Query, Zustand
**Storage**: localStorage (theme preference), Backend API (tasks via Module 3)
**Testing**: Vitest for unit tests, Playwright for E2E
**Target Platform**: Web (responsive: 375px - 1920px)
**Project Type**: Web frontend (monorepo - `todo-web-app/frontend/`)
**Performance Goals**: LCP < 2s, 60fps animations, Lighthouse score ≥ 90
**Constraints**: ONLY Lightswind components (no custom CSS), await async params (Next.js 16)
**Scale/Scope**: Single user tasks, ~100 tasks per user, 5 main pages

## CRITICAL: Next.js 16 Patterns

### Async Params (MUST follow)
```tsx
// app/(dashboard)/tasks/[id]/edit/page.tsx
export default async function EditPage({
  params,
}: {
  params: Promise<{ id: string }>
}) {
  const { id } = await params  // MUST await!
  const task = await fetchTask(id)
  return <TaskForm task={task} mode="edit" />
}
```

### Server Components Default
- All page.tsx files are Server Components by default
- Add `"use client"` ONLY for components using hooks, events, or browser APIs
- Keep client components small and push data fetching to server
